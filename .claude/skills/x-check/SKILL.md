# X の文面の点検

確認する順:
1. **1行目**: 数字つきの言い切りか(問いかけ・キャラの口調で始めない)。ミカタ新聞・理論ぶつけは「場名+R+締切」
2. **1行1情報**。結論は2行目に「→ 」で。3行目以降は今日の該当レース(「今日なら◯◯R」)→ 最後にミカタのひと言。ゲンさんのセリフは本文に入れない(画像の中)
3. **言葉**: 「◯%」「47%→66%」/ 人気どおり・人気以上・ひかえめ / 逃げ率・ST・展示・カド。「100レースで◯回」「オッズ」「信頼区間」が残っていないか
4. **主語**: 数字ごとに「だれの・どのレースの」話かが書いてあるか(「◯◯の選手が3着以内に入る割合」「◯◯のとき、1号艇が勝つ割合」)。くらべる相手(ふだん/風2m以下など)も。レースの6人みんなが同じ条件(暑い日・初日)で選手全体を比べていないか(必ず半分になる)
5. **出さないもの**: 買い目・的中・回収率・配当額・「必ず」。選手をけなす表現(不利な話は艇番だけ)
6. **長さ**: 全角2文字で数えて256以内(タグ2個を足して280)。`from kyotei.xtext import xlen`
7. **今日の該当レース**: 20:00 の投稿は「〜だった。明日の出走表でも探してみて」、15:30 は締切がまだ先のレース(「締切◯◯」つき)

見方: `reports/lab/<id>.json` から `lab.x_text(t, hits)` / `lab.neta_text(r, from_poll, hits)`、理論ぶつけは `theory_daily.build()` の x。直すのは scripts/lab.py(x_text / x_first_line / neta_text / today_line)、scripts/theory_daily.py、scripts/ura_auto.py(news_posts)
